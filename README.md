# Product Price Comparison

## Project Overview
Product Price Comparison is a web application that allows users to compare product prices offered by different dealers.

## Project Objectives
- Display available products.
- Show dealers that supply a selected product.
- Display the price offered by a selected dealer.
- Compare prices across all available dealers.

## Technologies Used
- HTML, CSS and JavaScript
- Node.js
- Microservices
- IBM Cloud Code Engine

## Application Components
- **Product Details Service:** Provides product information.
- **Dealer Details Service:** Provides dealer and pricing information.
- **Frontend:** Allows users to select products and dealers and view prices.

## Expected Outcome
The application helps users compare prices across dealers through a simple web interface.
